# InventorBatchPrint

**IT** — Esporta in batch le tavole di Autodesk Inventor in PDF o DWG (o stampale) direttamente dall'albero di un assieme. Software gratuito per Windows.

**EN** — Batch export of Autodesk Inventor drawings to PDF/DWG (or print) straight from an assembly tree. Free Windows tool.

**Sito / Website:** https://Burazz99.github.io/inventorbatchprint/
**Download:** [Ultima versione / Latest release](https://github.com/Burazz99/inventorbatchprint/releases/latest)

## Cosa fa / What it does

* Export PDF e DWG in batch, o stampa diretta, sulle tavole selezionate / Batch PDF \& DWG export or print
* Controlla i riferimenti mancanti e dice quale file manca / Detects missing references and names the file
* Un errore non ferma il batch: riepilogo unico a fine lavoro / One failure doesn't stop the batch
* Ricerca nell'albero, filtri e preset / Tree search, filters and presets
* Tema chiaro e scuro, log su file / Light and dark theme, file log

## Requisiti / Requirements

* Windows 10/11 (x64)
* Autodesk Inventor 2024–2028
* Nessuna installazione di .NET richiesta / No .NET install needed

## Problemi e suggerimenti / Issues and feedback

Apri una segnalazione nella scheda **Issues** (Open an issue in the **Issues** tab). Se puoi, allega il file di log: nel programma usa il pulsante **Apri cartella log**.
